# tabs-icon-panel

Custom **tabs** block. Purpose: self-contained tab component switching between tier panels, each with intro text and a row of icon features.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: cell 1 is the tab label; cell 2 is the panel: eyebrow paragraph, tier name heading, tagline paragraph, then per feature an icon (image or :icon:) followed by a heading and a paragraph.

No variations.
