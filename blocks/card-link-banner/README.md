# card-link-banner

Custom **card** block. Purpose: single horizontal linked card with an icon tile, title, description and chevron; the whole card is clickable.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: cell 1 icon or image; cell 2 heading (or bold title), description paragraph and a link to the destination (the first link in the cell covers the whole card).

## Supported variations

No variations.
