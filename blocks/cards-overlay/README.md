# cards-overlay

Custom **cards** block. Purpose: linked image cards with eyebrow and title overlaid on the photo.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: cell 1 image; cell 2 optional eyebrow paragraph, title heading and link (the last link covers the card).

## Supported variations

No variations.
