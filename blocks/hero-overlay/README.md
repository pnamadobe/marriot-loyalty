# hero-overlay

Custom **hero** block. Purpose: full-bleed photo with an overlaid heading, subtitle and CTA buttons (page hero and join banner).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background image; row 2: heading (H1 for the page hero, H2 elsewhere), subtitle paragraph, CTA links (bold = primary button, italic = secondary), optional location/caption link.

## Supported variations

No variations.
