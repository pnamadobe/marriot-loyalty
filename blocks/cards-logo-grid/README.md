# cards-logo-grid

Custom **cards** block. Purpose: brand-category cards, each with title, description and a grid of linked brand logos.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: optional cell 1 image; cell 2 title heading, description paragraph, then paragraphs of linked logo images (gathered into the logo grid).
