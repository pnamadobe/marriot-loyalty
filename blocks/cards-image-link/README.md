# cards-image-link

Custom **cards** block. Purpose: grid of linked image cards (image, title, description) where each card links to a detail page.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: cell 1 image; cell 2 title heading, description paragraph and link (the last link covers the card).

## Supported variations

No variations.
