# table-comparison

Custom **table** block. Purpose: benefit comparison matrix across membership tiers with check icons for included benefits.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: corner label then one cell per tier (tier name and qualifying nights); then one row per benefit: cell 1 bold benefit name, description and optional "More Details" link; one cell per tier holding a check icon (included), a short value, or nothing (not included).

No variations.
